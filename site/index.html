What it does

The marks are the point.

Type the text and the rules place the marks: which syllable is held and for how long, where an accent falls, where a pause belongs, what an anusvāra becomes before a sibilant. Where a rule is wrong for a particular word, you overrule it — and your decision survives every later edit, because it is attached to the letter and not to the picture.

Different texts, different rules

A Ṛgvedic sūkta and a purāṇic stotra are not marked the same way. Five registers — Taittirīya, Ṛgveda, Śukla Yajurveda, smārta and prose — and the document says which it follows, per document or per section.

One to one with the Word file

The page on screen is the page that prints. Sizes, leading, indents and margins are taken from the documents themselves, and a browser test measures them on every build so they cannot drift.

Three ways to look at it

A flowing column for writing, real pages for checking what the PDF will be, and a full-width web view. Same document, same marks, no re-flow surprises between them.

A recitation against the text

Open a recording and the program works out which second is which pāda — by listening for the breaths and by counting syllables. Then the line lights up as it is sung, and clicking a line plays it.

What was copied stays copied

A verse transcribed from a hand-marked page is evidence: its marks exist nowhere else, so the program will not re-derive it and says so plainly rather than quietly rebuilding it.

Devanāgarī, Telugu and Tamil

The same marked text in four writing systems, derived rather than typed twice — so a correction is made once.

Its own files

.smdoc, and it stays readable.

Once installed, śikṣāmitra owns .smdoc files and gives them their own icon. Version 2 opens every version 1 document; a document saved today will open in whatever version 5 turns out to be, because the format's rule is that a reader may not be broken by a writer it has never met.

Word in and Word out, PDF, and .vuchant packages that carry a document with its recordings and figures.

For agents and scripts

Everything the window can do, a command can do.

Not a convenience — the design. Both call the same code, so a power one of them has cannot rot in the other. Nothing is written without --write. 

sm import durga.docx --out durga.json      # a marked Word file, read
sm set-register durga.json --preset rigveda --write
sm hold durga.json --verse v-2 --units 0-4 --value long --write
sm audio map durga.json --file take.wav --write
sm export durga.json --out durga-out.docx
